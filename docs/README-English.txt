TypeTrail 1.0.1 — Windows x64, including 32-bit input applications

Install TypeTrail-Setup-1.0.1-x64.exe, or run TypeTrail.exe from the portable folder.
Requires .NET Framework 4.8 or later. Install the official Microsoft runtime if prompted.
Alt + ` opens or hides history; the tray icon also opens it.
The theme button switches light/dark mode. The globe menu offers English and Chinese.

Capture follows foreground applications automatically. Committed Chinese text is
retained after candidate selection. Select a portion to copy, or copy the whole entry.
Retention follows the configured character budget. Original field content, cancelled
preedit, standard password fields and excluded applications are omitted.
History stays local and encrypted. Installation, updates and uninstall retain data.

Entries follow their update time. Selection replacement, middle insertion, Backspace
and Delete are tracked within captured text. Clearing an entry leaves an empty marker;
retained earlier drafts are available from the version selector. Uncertain navigation
retains a labelled earlier fragment.

Data is stored in %LOCALAPPDATA%\TypeTrail. History is compressed and encrypted for
the current Windows user. Pause capture or exclude an application before entering
passwords, verification codes, keys or other sensitive information.

Coverage remains bounded for secure desktops, protected/higher-integrity processes,
raw-key custom editors without text events, and custom paste with no accepted-insertion
evidence. Extreme queue pressure and hung providers may cause partial capture.
TypeTrail recovers input text; it cannot reconstruct every editor's exact document,
selection and caret state.

With history saving enabled, normal exit is cancelled if new history cannot be saved.
Capture stays in memory until storage recovers. Forced termination or power loss can
still lose unsaved content. Keep separate copies of important text.
