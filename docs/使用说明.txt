拾字 1.0.2 — Windows x64（兼容 32 位输入程序）

安装 TypeTrail-Setup-1.0.2-x64.exe，或运行免安装目录的 TypeTrail.exe。
需要 .NET Framework 4.8 或更高版本；缺少时请先安装 Microsoft 官方运行环境。
Alt + `（Esc 下方、数字 1 左边）打开或收起历史，也可点击托盘图标。
主界面太阳/月亮按钮切换深浅色；地球按钮下拉选择简体中文或 English。

自动跟随前台应用，无需逐个添加。中文以选词后确定的文字保存。
可拖选复制一部分，也可复制整段。保存数量按设置的字符预算计算。
原有字段内容、取消的拼音、标准密码框及被排除的应用不应进入历史。
历史保存在本机并加密；安装、升级、卸载均保留原有历史及设置。

历史按更新时间排列；支持已捕获文字范围内的选区替换、中间插入、退格和
向前删除。删空会显示“已清空”，完整旧稿保留在版本下拉框中；无法可靠
跟踪的定位操作会保留为带标识的修改前片段。

数据位于 %LOCALAPPDATA%\TypeTrail。历史经过压缩，再用当前 Windows 用户
身份加密。输入密码、验证码、密钥等敏感信息前，请主动暂停或排除相关应用。

覆盖仍有边界：安全桌面、受保护或更高权限应用、仅处理原始键码而不公开
文字事件的自定义程序不能保证记录。只有剪贴板提示、缺少真实插入证据的
自定义粘贴也不能保证保存。极端队列溢出及卡住的提供程序会提示部分录入。
本程序用于找回输入文字，不保证重建所有编辑器的精确光标、选区和文档状态。


开启保留历史后，若新记录尚未写盘，正常退出会被取消并提示；存储恢复后可
继续保存。强制结束进程或断电仍可能丢失未保存内容，重要文字请及时另存。
